# Branch pilot ops v1.0 (issue #95) — humans adopt, not just systems

3 branches (1 urban flagship, 1 suburban, 1 rural/provincial) for 6 weeks.

## Training pack (role-based, 1 day + shadow week)

- All staff: what the OS is, what changed in THEIR queue (H74), how to escalate,
  degraded-mode paper lane (H80) with live drill.
- Managers: caps/authority unchanged (B11), pause rights (J92), daily ritual (J92).
- RM/officers: AI drafts are drafts (G64/G65), explainer language for customers (I86).
- Shadow week: new system mirrors live work, staff compare + flag mismatches;
  go-live needs <2% unexplained mismatch + manager sign-off per branch.

## Rollback criteria (any one triggers branch-level rollback in 1h)

- Sev1 or PII incident; TTA 2× baseline for 3d; CSAT drop >0.5; staff override
  rate >50% (the system isn't helping); branch manager unilateral call.
- Rollback = paper + legacy queues resume; OS stays in shadow mode for diagnosis.
  Re-entry needs root cause + fix + fresh shadow week.
